Note on polymer SMILES invariance: Polymer SMILES have a couple of invariances worth keeping in mind:

- **Translational invariance** — where the same polymer can be represented using different forms just by translating the elements.
- **Repetition (oligomer) invariance** — writing the repeat unit once, twice, or three times in a row (monomer vs. dimer vs. trimer) still represents the same polymer; the string length shouldn't matter.
